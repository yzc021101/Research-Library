# 投研纵览 · research_library

投研纵览是一个本地资料检索工具，支持 macOS 和 Windows。选好存放资料的文件夹后，就可以在 App 里搜索，也可以通过 MCP 让 Claude Code、Codex、WorkBuddy 等 AI 工具检索这些文件。

做研究时，几份文件可以直接拖进聊天框。积累到几十、上百份以后，每次找文件、上传、补充上下文就很费事。这个软件想解决的就是这一步：把本地报告、纪要、访谈、Word、PPT 和表格建成索引，提问时找出相关段落，并给出文件名和原文位置，方便继续核对。

下载向量模型后，可以按意思检索，不必记住原文用了哪个词；也可以用关键词搜索。新增、修改或移除文件后，索引会按设置自动同步。扫描件和文档中的图片文字可以通过可选 OCR 组件识别。我主要把它用在投研资料上，论文、工作文档和其他本地文件也可以放进来。

目前它以MCP检索功能为主，以后我可能加入更多功能，把它做成一个相对个性化的投研工具箱。欢迎在 [Issues](https://github.com/yzc021101/Research-Library/issues) 反馈不好用的地方，或者提出想加的功能。

## 下载与安装

> [!IMPORTANT]
> **自动更新提示**
>
> 目前自动更新功能还不够稳定，版本检查和安装包下载依赖 GitHub。中国大陆用户可能需要科学上网（使用可访问 GitHub 的代理网络），下载速度也可能较慢。
>
> 如果检查更新或下载长时间卡住，可以直接从 [GitHub 下载页面](https://github.com/yzc021101/Research-Library/releases/latest) 获取安装包，退出 App 后进行手动更新。Mac 使用 DMG 替换应用，Windows 运行 setup.exe 安装到原位置；请保留原有资料库目录。

[下载发行版](https://github.com/yzc021101/Research-Library/releases)。Mac 版本适用于 Apple Silicon 与 macOS 14 及以上；Windows 版本适用于 Windows 11 x64，可在 Windows 11 ARM 的 x64 兼容环境运行。

- Mac：打开 DMG，把“投研纵览”拖到“应用程序”。
- Windows：下载 `research_library-windows-x64-setup.exe`，按向导安装，可分别勾选开始菜单和桌面快捷方式。也提供 ZIP 便携版，需完整解压并保留同目录所有文件。缺少 Microsoft Visual C++ 运行库时，App 会从微软官网下载、验证数字签名并打开安装程序，请自行确认微软许可与系统安装提示。
- 基础包含 Python 及基础解析依赖；Windows 还包含 .NET 和 WinUI 运行库，无需安装开发工具。
- 设置里的“运行环境与可选组件”可以下载 OCR 与旧版 Office 转换组件。显示下载大小和进度，校验通过后安装；可取消或重试。安装或移除后重启服务。
- 向量模型独立按需下载。未下载模型时可使用关键词检索。

发行版使用本地签名，未购买 Apple Developer ID 公证或 Windows 商业代码签名。请核对官方仓库来源及 SHA256SUMS，通过系统正常安全提示允许运行，勿关闭系统安全保护。

## 检查更新

在“设置 → 软件更新”中检查 GitHub 正式发行版，选择下载，再点击“安装并重启”。更新只替换应用程序，保留资料库、模型、来源文件夹和 MCP 配置。安装包先校验 GitHub 提供的 SHA-256，完整准备后才替换旧版；替换失败会保留或恢复旧版。

下载与安装会显示独立进度窗口；下载时显示已下载大小和总大小，安装阶段显示当前状态。

可选“自动更新”默认关闭。开启后，App 运行时每天检查并下载一次更新，下载完成后仍由你选择安装并重启。更新检查只访问本项目 GitHub Release，不上传资料内容。请保留至少 5 GB 空闲空间，使用可写的安装目录。

## 支持的资料

PDF、DOCX、PPTX、XLSX、Markdown、TXT、RTF、CSV、TSV。DOC/PPT/XLS 通过可选 LibreOffice 组件转换；扫描 PDF 和 Office 内嵌图片通过可选 Tesseract OCR 识别。表格公式读取缓存值，不重新计算；OCR 和旧版格式转换的关键数字应回看原件。

默认关联来源文件，不复制原文。自动同步按设置检测新增、修改和移除的文件。原文快照为可选项，可在设置中清理。

入库记录区分“已入库”“部分入库”“导入失败”和“已跳过”。正常读取后没有可检索文字的文件记为“已跳过”，不进入失败重试；内容变化后仍会重新检查。未完成 OCR、超出读取额度或缺少公式计算结果的文件会列出原因和位置；可以逐个重试，也可以一键重试所有未完整入库文件。已完整入库的文件保持原记录。

Excel 检索与表格预览默认显示文件已保存的计算结果，并应用常见百分比、金额、小数和缩放格式；原公式只在详情中保留。没有缓存结果时明确提示缺失，原文件中的 `#REF!`、`#DIV/0!` 等错误值原样保留为原表提示，不因此判定整份文件导入失败。应用不执行公式、宏或外部数据刷新；需要新结果时请在 Excel 中计算、保存，再同步。

模型在独立进程中按需运行，空闲五分钟后释放，下次检索时重新载入。关闭自动扫描后停止周期性遍历来源文件夹。

## MCP 接入

首次启动自动显示引导，可分别选择是否安装向量模型和 OCR；默认推荐轻量多语言 MiniLM，点击安装才下载，也可稍后配置。随后选择资料文件夹、客户端并复制 MCP 配置；整个流程在同一窗口完成。已完成或跳过的引导不会在普通重启或升级后反复弹出，设置中可以重新打开。支持本地 STDIO 的 Codex、WorkBuddy、Claude Code、Cursor、VS Code 等工具。本地接入不需要远程 URL 或 MCP Key。移动 App 后重新复制配置。在客户端调用 `library_status` 验证连接。

## 隐私

默认不上传用户资料。索引、设置、日志、缓存与可选组件集中保存在 Mac 的 `~/Library/Application Support/research_library` 或 Windows 的 `%LOCALAPPDATA%\research_library`。下载组件、模型及打开帮助链接会访问对应发布站点。通过 MCP 交给 AI 客户端的原文片段会进入该客户端的对话环境，请按自己的资料授权范围使用。

安装包不含开发者资料、索引、账号配置或模型缓存。初次运行创建个人资料目录。Windows 安装版可通过系统“已安装的应用”或控制面板卸载：关闭本安装位置的应用，移除程序、快捷方式及匹配的登录启动项；自动更新新增的程序文件也按清单清理。单独的资料库、模型和来源文件保留。若 AI 客户端仍在调用 MCP，请先关闭该连接再卸载。ZIP 便携版直接移除程序目录即可。Mac 可删除 App；自己的资料目录可按需要另行清理。

## 0.6.12 改进

- 索引时继续检索已完成入库的资料，并明确提示当前覆盖尚不完整；短暂写入繁忙时返回可重试状态。
- 根据 CPU 和可用内存安排有上限的并行解析与 OCR。普通同步跳过未变化文件；解析规则升级只处理受影响的文件，复用未变化文本的向量。
- 无可检索文字的正常文件记为“已跳过”；Excel 原有公式错误保留为原表提示。真正的损坏、读取截断、缺少公式缓存或 OCR 失败继续单独提示。
- PPT 展示标题优先采用文件名，保留原始内嵌标题；PDF 检索文本隔离可识别的重复使用声明，原文与独立声明信息保留。
- 首次启动引导增加向量模型与 OCR 选择，推荐 MiniLM；支持稍后配置、已有组件检测、安装状态和取消重试。
- MCP 使用独立的固定版本运行目录，避免后续更新替换仍在使用的模块。已结束连接的过期运行目录会在后续启动时清理。

**从 0.6.11 或更早版本升级：** 若 AI 客户端此前一直保持 MCP 连接，请升级后在客户端重新加载一次 `research_library`（或重启该客户端）。旧进程已缓存的模块位置无法由新安装包追溯修复；出现 `unknown encoding: idna` 时，同样按此操作。Windows 用户还需从新版“MCP 接入”页复制一次配置，改用稳定启动入口。之后由新版入口启动的连接使用固定版本运行目录。

## 0.6.8 读取兼容性改进

- Excel 按有效单元格读取，默认 200 万格；设置中的大文件模式提高到 500 万格。空白行列和错误的工作表范围不会占用有效内容额度。
- 表格按块保留字段上下文；检索采用保存的公式结果，原公式和数字格式可在表格详情中核对。程序不执行公式或宏。
- 根据文件内部格式识别扩展名为 XLS 的 XLSX、HTML 和 XML 表格；原文件不改名、不改写。
- 超长 PDF 页面分区 OCR，普通超大页面自动调整识别分辨率。失败区域会明确提示，其余正文可继续入库。
- 大文件中间结果使用临时磁盘存储，向量分批生成。达到额度时显示“部分入库”及停止位置；提高额度后重新同步即可继续处理。
- 仅在读取副本中兼容无效打印标题和对齐样式；不改变工作表、单元格、原公式或来源文件。

大文件模式同时提高文本额度（3200 万至 8000 万字符）和读取时间额度（5 至 15 分钟）；首次索引可能较慢，建议接通电源后使用。上述时间额度针对表格行扫描，不包含随后进行的图片 OCR 和向量生成。

内嵌 WMF/EMF 矢量图片的 OCR 需要设置中的可选 Office 转换组件；未安装或转换失败时会保留已读取的正文，并明确提示遗漏的图片。
