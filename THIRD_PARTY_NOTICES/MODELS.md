# Optional embedding models

No model weights are included in the application or optional component packages. Downloaded model files stay in the user's data folder. Model licenses remain separate from the application license.

| Model payload source | License |
| --- | --- |
| https://huggingface.co/qdrant/paraphrase-multilingual-MiniLM-L12-v2-onnx-Q | Apache-2.0 |
| https://huggingface.co/Xenova/paraphrase-multilingual-mpnet-base-v2 | Original sentence-transformers model: Apache-2.0; conversion repository does not separately declare a license in its model-card metadata |
| https://huggingface.co/qdrant/multilingual-e5-large-onnx | MIT |

Consult each repository's model card and license before using or redistributing model weights. The original model families are sentence-transformers multilingual MiniLM/MPNet and intfloat multilingual E5. Downloaded ONNX conversions retain upstream model rights.
